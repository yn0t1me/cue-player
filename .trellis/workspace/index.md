# 开发日志入口

这里保存整理后的开发日志。首次公开不导入旧个人日志或旧提交流水；后续开发者在自己的目录中记录实际发生的工作，并随公开仓库版本管理。

## 开始记录

从项目根目录初始化本机开发者身份与个人日志目录，将 `your-name` 替换为自己的开发者名称：

```bash
python3 .trellis/scripts/init_developer.py your-name
```

开发者身份文件仅留本机；个人索引和日志用于公开记录。已有身份时按 [AGENTS](../../AGENTS.md) 和 [workflow](../workflow.md) 加载当前任务，再按实际结果记录会话。

## 文件职责

- `<developer>/index.md`：个人日志索引，由 Trellis 维护会话条目。
- `<developer>/journal-N.md`：整理后的目标、修改理由、验证结果与限制。
- [任务目录](../tasks/)：开发任务及其归档，与个人日志分开管理。

此总入口不手工重复各开发者的会话计数或任务状态。日志概括结果，不抄录原始私人聊天；记录可定位的公开任务和提交，尚未提交时如实说明。公开内容检查及文档效力见[文档规则](../../docs/README.md)。
