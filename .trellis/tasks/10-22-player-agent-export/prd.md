# 播放器与 Agent 学习素材导出产品重构

## 目标与状态

将视频播放与学习一体的产品收敛为服务外部 Agent 学习的播放器与素材采集工具。产品负责观看、字幕阅读、表达收藏和材料导出；概述、讲解和表达学习在 Agent 中完成。

用户已批准最终规划并明确授权实施。当前处于 in_progress。本任务记录已确认的新方向，实施过程中同步相应规范；下文基线证据描述实施前行为。

## 已确认的学习流程

1. 导入视频，第一次自行观看。
2. 单独导出完整字幕，交给 Agent 概述和讲解视频。
3. 学习后第二次观看，选中并收藏仍不理解的表达。
4. 单独导出收藏表达及所在字幕条目，交给 Agent 学习这些表达。

两次导出服务于不同阶段，不合并输出。这是使用流程，不自动授权引入强制阶段、学习进度或完成状态。

## 需求

- R1：保留视频播放、字幕阅读、中文翻译和词块视图。保留现有初始英文字幕 → 外部 AI 加工 → 预览、导回发布流程。
- R2：标记简化为选中英文表达并收藏、取消收藏；保留表达与所在字幕条目的关联，不提供备注、问题和解答编辑。
- R3：独立导出播放器当前使用的完整学习稿，不额外提供 Raw 来源选择。英文原文始终包含，用户选择是否包含中文翻译和词块。
- R4：独立导出收藏表达及其所在字幕条目的原文，不加前后条目；即使该条目只有半句话，也不补齐或拼接，不重复附上完整视频字幕。
- R5：两种学习材料导出都不附带提示词、学习指令或练习要求，用户在 Agent 中已有说明。字幕加工流程原有的加工指令不在此删除范围内。
- R6：移除备注、问题和解答功能，并清除对应已有数据。用户明确说明当前是开发阶段，不需要兼容这些旧功能和数据。该授权不扩展为删除视频、字幕或收藏表达；实际清理已随 015 迁移完成，保留数据核对见 validation.md。
- R7：完整字幕和收藏表达两种导出都提供一键复制与下载 Markdown 文件。
- R8：保留现有单视频、多链接和播放列表导入，以及合集管理。本次围绕播放页、收藏和导出调整产品功能，移除备注问答；不重做导入和合集产品流程。
- R9：播放页沿用播放器旁的工作区，收敛为“字幕 / 收藏”两个标签页，移除“问题”标签。完整字幕导出放在字幕页，收藏表达导出放在收藏页，不采用字幕和收藏同时显示的布局。
- R10：两种导出均保留视频标题，不附带时间戳、字幕版本等内部信息。完整字幕按字幕原顺序排列，收藏按视频中的出现顺序排列。
- R11：保留现有 Raw 和当前学习稿的 SRT 下载入口，继续置于字幕管理工具中，与面向 Agent 的材料导出分开，不占主要导出入口。
- R12：未加工出中文或词块时只导出英文，不显示缺失说明、占位文字或置灰原因提示。仅呈现当前材料实际可提供的导出选择，不自动补充内容。
- R13：发布新字幕后，旧版本收藏继续保留创建时的表达与所在字幕原文，仍可查看和导出，不自动迁移或清空。

## 范围外

- 应用内概述、教学、问答、练习和掌握程度判断。
- 学习材料中的 Agent 指令，以及合并两次导出的学习包。
- 自动选择表达或强制学习阶段。
- 退役备注、问题和解答的兼容流程。
- 以代码分层、架构或技术栈重写为本任务目标。

## 验收标准

- AC1 / R1：字幕加工与导回流程可用，播放器支持中文翻译和词块阅读。
- AC2 / R2：可选中英文收藏和取消收藏，没有备注、问题和解答入口。
- AC3 / R3、R5：可独立导出当前学习稿的完整英文字幕，无 Raw 来源选择，可选择是否包含已有中文和词块；不含学习指令。
- AC4 / R4、R5：可独立导出收藏表达及所在字幕条目，不含前后句、整段字幕或学习指令。
- AC5 / R6：已有备注、问题和解答被清理，相关功能退出产品；视频、字幕和收藏表达不会因该清理被一并删除。
- AC6：两种导出可分别执行，不要求同时导出两种材料。
- AC7 / R7：两种导出都可一键复制或下载 Markdown 文件，同一选项下两种方式包含相同的学习材料。
- AC8 / R8：单视频、多链接和播放列表仍可导入，合集仍可管理，既有批次进度和失败重试不因功能收敛失效。
- AC9 / R9：播放页仅有字幕和收藏两个工作区标签，两种导出入口分别位于对应标签页。切换标签保持播放器、播放时间及播放状态。
- AC10 / R10：复制文本和 Markdown 均包含视频标题，完整字幕及收藏顺序符合要求，材料中没有时间戳或字幕版本字段。
- AC11 / R11：字幕管理工具仍可下载 Raw 和当前学习稿 SRT，Agent 材料导出不增加 Raw 来源选项。
- AC12 / R12：仅有初始英文字幕时，两种交付方式均可直接得到英文内容，不出现“无中文”“无词块”等说明或占位内容。
- AC13 / R13：发布新学习稿后，旧收藏的表达、原字幕上下文不变，仍可导出和取消收藏。

以上是实施验收要求，不代表已实现或通过验收。具体验证与执行顺序见 implement.md。
