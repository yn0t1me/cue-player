# 开发任务

后续开发任务默认随公开仓库版本管理，使用 Trellis 的 PRD、设计、执行计划、上下文清单和归档生命周期。任务中的提案、已批准范围、执行状态和验证结果分别标明；当前产品规则由 [spec](../spec/index.md) 维护。

首次公开从空任务列表开始，不导入旧里程碑、Bootstrap 或本次开源整理的过程目录，不重建历史任务。需要开始新工作时，按 [AGENTS](../../AGENTS.md) 加载会话并使用 [workflow](../workflow.md) 创建、执行和归档任务。

公开记录与资料审阅规则见[文档说明](../../docs/README.md)。身份、会话运行态和临时文件继续忽略；它们不是任务版本历史的一部分。
